Plug and play adapters that turn frozen generative models into action conditioned world models

How we add action control, and fast multimodal prediction, to a large pretrained video diffusion model without ever retraining it.

The setup

One frozen prior plus one small trainable correction

  • Large pretrained video diffusion models are excellent generative priors, but they have no action input and can't be used directly as world models.
  • Retraining a billion parameter video model is out of scope. So we freeze the base and learn a small adapter that adds the missing behaviour.
  • Everything in this talk is one composition rule:
f(xt, t, at, d) = fbase(xt, t) + g(d) · Δφ(xt, t, at, d)

at = action · d = generation step size · the base stays frozen, only Δφ is trained.

Base model: DynamiCrafter (video). Domain: MetaWorld robot manipulation.

The framework: what kind of adapter?

Three ways to attach the correction

HyperAlign

A hypernetwork generates per layer LoRA weights that are injected inside the frozen UNet's attention layers.

UniCon

A hidden state adapter: a trainable decoder replica reads the frozen base's internal feature maps.

Output adapter (AVID style)

A trainable network reads only the frozen base's final output and emits a residual correction. The lightest coupling, and the cheapest to train, as the next slides show.

Why the choice matters

The hidden cost: gradient flow through the frozen base

  • "Frozen" saves weight updates, not backprop. The deciding question is: is the frozen base in the gradient graph?

HyperAlign / LoRA

Inject weights inside the base, so the gradient must backprop through the entire frozen UNet. Needs gradient checkpointing, and runs the base 2 to 3 times per step.

UniCon

Detaches the base, but its trainable decoder replica is heavy and coupled to interior features: a large backward graph by construction.

Backprop cost is set by where the adapter attaches and how big its own graph is, not by trainable parameter count. Two adapters with equal parameters can differ by an order of magnitude in training memory and compute.

The output adapter

Reads the base output as a constant, so backward stays cheap

  • The frozen base runs once, detached (torch.no_grad). Its output is just data fed into the adapter.
  • Backward touches only the adapter. The frozen base is never in the gradient graph.
  • You control the adapter's size; the base is fully decoupled. This is why the output adapter is our lightweight, flexible substrate, and the foundation for both directions later.
base (no grad) → constant input → adapter → δ  |  gradient stops at the base boundary
⤷ Output adapter architecture
Output adapter: variants

What the adapter emits: direct vs affine

direct

Emit the correction itself: δ, added to the base prediction. final = base + δ.

affine

Emit a (scale, shift) that modulates the base prediction: δ = base·scale + shift → final = base·(1+scale) + shift.

direct  a delta for every element

One delta value at every (channel, pixel): full resolution, same shape as the latent.

affine  one (scale, shift) per channel

A single (scale, shift) per channel, identical across all pixels in that channel.

Affine is a strict superset of direct (force scale = 0 and you recover direct). The extra multiplicative term can gate the base prediction per channel. We compare whether that earns its keep.

What we condition the adapter on

Two targets: action, and step size (shortcut)

Action conditioning

Feed the action at so the adapter predicts the action conditioned next frame. This is the world model behaviour.

Shortcut (step size d)

Condition on the generation step size so the model can take big jumps: few step rollout instead of roughly 50 denoising steps.

  • Action conditioning works today. The AVID style output adapter is our running baseline.
  • Shortcut training is in progress on the output adapter.

Direction 1: the goal

An action conditioned and shortcut output adapter

  • Combine both targets in one adapter: it predicts action conditioned transitions and does so in few steps.
  • Result: a world model fast enough to roll out trajectories for planning and control.
action conditioning (world model)  +  shortcut (few step)  =  fast action conditioned rollout

Direction 2: building on the output adapter

A multimodal output adapter for coupled sensory prediction

  • The output adapter is the most lightweight family, so it's the natural substrate to scale out, not just speed up.
  • A world model should predict more than pixels: proprioception, depth, touch, force.
  • Idea: one adapter per sensory modality. Each emits (i) a correction to the video prediction and (ii) its own sensory signal, fused by a learned mask.
⤷ Multimodal output adapter architecture

Independent per modality timesteps mean one trained model answers many queries: policy, forward and inverse dynamics, video only prediction, by choosing which streams start from noise.

In one picture

One lightweight substrate, two directions

  • Output adapter: frozen base plus a cheap, decoupled correction (no backprop through the base).
  • Direction 1: action conditioned plus shortcut → a fast world model for control.
  • Direction 2: one adapter per modality → multimodal coupled prediction.
