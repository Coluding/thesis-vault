Multimodal compositional output adapter

Frozen video base + one trainable output adapter per sensory modality. Each adapter emits (i) a correction to the video (pixel) noise prediction and (ii) a prediction of its own modality's noise. A learned mask aggregates the video corrections; each modality keeps its own output.

Zoom: what each modality adapter emits

Every modality adapter is dual-headed. One head produces a correction to the video noise (εadj,i) — "given what this sensor tells me, here's how the pixel prediction should change." The other head produces that modality's own noise prediction (εi) — proprioception, depth, tactile, etc. The video corrections from all adapters (plus the action adapter and the frozen base) are blended by the learned mask m into a single video prediction; each modality's own head is supervised directly. The action adapter is the degenerate case with only the video-correction head — it is exactly today's single-modality AVID-style output adapter, recovered as n = 0.

n = number of extra sensory modalities · m ∈ ℝn+2 = learned fusion mask over { base, action, modality₁…ₙ } · wm = per-modality loss weight. Generalises the single-modality AVID-style output adapter (avid.html): set n = 0 and the mask reduces to the AVID gate εt = m⊙εadj + (1−m)⊙εpre. Each modality is noised at an independent timestep tm (UWM scheme), which makes conditional / marginal queries — policy a|x, forward / inverse dynamics, video-only prediction — fall out of the one trained model by choosing which streams start from noise. The frozen base only ever sees the video stream; the sensory streams are produced entirely by the trainable adapters.
