Equations

Eq. 3 — exact step Xn+1 = Xn + (tn+1 − tn) un(Xn) Exact, not approximate — because un is defined as the integral average.
Eq. 4 — mean velocity un(Xn) = 1/(tn+1 − tn) ∫tntn+1 vt(Xt) dt
Eq. 5 / 6 — teacher targets Euler:    un(Xn) ≈ vtn(Xn)    (1 teacher call)
Midpoint: un(Xn) ≈ vtmid(Xmid),  Xmid = Xn + ((tn+1−tn)/2)·vtn(Xn),  tmid = (tn+1+tn)/2  (2 calls) Midpoint consistently outperforms Euler in the paper's ablations (Fig. 6, Tables 3–5).
Eq. 8 — parallel decoder ūθn(k | Xn) ≈ uk(Xk),   k = n, …, n+L−1 Well-defined because the whole block is determined by Xn alone.
Eq. 9 — parallelized process X̄k+1 = X̄k + (tk+1 − tk) ūθn(k | Xn),   X̄n = Xn Simulated from a single decoder evaluation — ū depends only on Xn.
Eq. 10 — block step (sampling) X̄n+L = Xn + Σk=nn+L−1 (tk+1 − tk) ūθn(k | Xn)
Eq. 11 — the PD loss ℒPD(θ) = 𝔼 ‖ ūθn(k | Xn) − uk( sg( X̄k ) ) ‖² n ~ U{0, L, …, N−L}; k ~ U{n, …, n+L−1}; Xn from the interpolant (Eq. 2); uk from one RK step. Proposition 1: the minimiser satisfies Eq. 8 — i.e. the student reproduces the teacher's trajectory up to RK error.
Eq. 12–13 — architecture Teacher: vt(x) = W Ht(x)   →   Student: ūθn(k | xn) = Wθk Hθtn(xn) Shared backbone; N replicated final linear layers, each initialised from the teacher's W. N heads (not L) ⇒ one model serves several block sizes with no second time coordinate.
Eq. 14–15 — layer fusion X̄n+L = X̄n + (tn+L − tn) Wθn:n+L Hθtn(X̄n)
Wθn:n+L = Σk=nn+L−1 Δk Wθk,   Δk = (tk+1 − tk) / (tn+L − tn) At generation only the block average is needed ⇒ store one fused layer per block ⇒ zero extra inference cost vs. the teacher.

Algorithm 2 — the loss, verbatim

N = len(t) - 1                                  # grid size
n = L_min * randint(0, N//L_min)                # sample block index
x_n = (1-t[n]) * randn_like(x) + t[n] * x       # sample the probability path
u = student(x_n, t[n])                          # parallel predictions
h = diff(t, dim=0)                              # step sizes
k = randint(n, clip(n+L_max, max=N))            # sample index in the block
x_k = x_n + einsum('l,l...', h[n:k], u[n:k])    # step from n to k  <- on-policy
u_k = runge_kutta(teacher, x_k, t[k], h[k])     # teacher mean velocity
loss = mse_loss(u[k], u_k.detach())

Data-free variant (Alg. 3): skip the interpolant entirely — sample X0 ∼ p0 and alternate solver steps with gradient steps, reusing the decoder output both to train and to advance the state (with stop-gradient), for N/L − 1 iterations.
