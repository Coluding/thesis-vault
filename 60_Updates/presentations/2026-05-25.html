Key finding

fs conditions the base, not the adapter

  • fs reaches the frozen base UNet, but Δ_φ (the trainable adapter) sees it only indirectly, via base activations
  • The MetaWorld dataset emits a constant stride (default 1) — no variation to learn from
  • A precedence bug feeds the slice stride into the base's fps channel
Net: for D2, frame stride is currently neither learnable nor varied — worth fixing before trusting any fs-related behaviour.
