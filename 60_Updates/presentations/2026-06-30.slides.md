# Recap: the flow-matching pivot

### why we changed the base (2026-06-19)

- The shortcut v-averaging bias is a **curvature effect** — κ=1 on the diffusion (VP) circle makes the averaging target subtly wrong.
- A **flow-matching base is κ=0** (straight trajectory): averaging is exact, the shortcut objective is faithful as written — **no target surgery**.
- **WAN (Wan2.1)** flow-matching DiT chosen as the front-runner frozen base; keeps the D1 diffusion ↔ flow span intact.

> The pivot is the *structural escape* from the bias — orthogonal to patching the diffusion target.

# Three findings this week

# Finding 1 — training is healthy

### loss converges cleanly on all three

- `base_loss` descends smoothly and stably for every run.
- On the flow base the **per-rung shortcut loss is well-behaved** (monotone in step size) — the v-averaging bias the pivot targeted is gone.
- Pooled shortcut-loss "volatility" confirmed to be a **step-size-mixing logging artifact**, not instability.

> All loss figures are **eyeballed off the W&B chart axes — not logged scalars**. Run ids / configs still `_needs verification_`.

# Finding 2 — samples are still poor

### loss health is no longer the blocker — generation is

- Videos recover the **coarse structure** (red arm + table + rail) in the better panels...
- ...but a large fraction show **blur, fog, collapse, and colour-drift** (orange/blue/green/magenta bleed), **degrading over the rollout**.
- Flow ±shortcut look broadly similar at this stage; can't yet compare at matched few-step NFE (grid layout `_needs verification_`).

> **Suspects:** undertraining (esp. the ~1.4k-step diffusion run) · resolution / VAE decode · action-conditioning strength · rollout drift.

# Finding 3 — flow is much faster

### the practical payoff of the pivot

- Flow runs **train and sample noticeably faster** than the diffusion run.
- Expected mechanism: straight κ=0 ODE → far fewer sampling steps.
- This is exactly what **D3/D4 few-step rollout for planning** needs.

> **Caveat — not a clean comparison.** Diffusion was higher-res (1536×1600 vs 768×1280) + a different backbone. Qualitative only; no logged steps/sec or sampling latency yet.
